## Architecural Principles
1. **Domain Separation** - Isolate security domains with controlled communication  
2. **Layering** - Defense in depth through multiple security layers  
3. **Encapsulation** - Protect internal components from external access  
4. **Redundancy** - ensure availability and integrity
5. **Virtualization** - sharing a single set of hardware among multiple operating systems

## Design Principles
1. **Least Privilege**
2. **Attack Surface Minimisation**
3. **Centralized Parameter Validation**
4. **Centralized General Security Services**
5. **Preparing for Error and Exception Handling**

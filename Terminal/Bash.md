# Bash

Bash (Bourne Again Shell) is a Unix shell and command language.

## Common Commands

```bash
# List process
ps

# Run by other users and those that don't run from a session (i.e. system processes)
ps aux 

# Watch process 
top

# Look up the IP address of a domain
nslookup 

# Show available network interfaces
ip a s

# Count the lines
wc
```

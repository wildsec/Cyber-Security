# Cmd.exe

Windows Command Prompt - the default command-line interpreter for Windows.

## Common Commands

```cmd
# The terminal output below shows the path where MS Windows will execute commands
set

# Get windows version
ver

# List various information about the system
systeminfo

# The command `tracert target_name` traces the network traversed to reach the target.
tracert

# It looks up a host or domain and returns its IP address.
nslookup

# Displays current network connections and listening ports.
# -abon for full view with PID
netstat

# cat equivalent
type

# List tasks
tasklist

# Telnet connection test
# telnet IP PORT
```

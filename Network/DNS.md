DNS traffic uses UDP port 53 by default and TCP port 53 as a default fallback
- **A record**: map ipv4 address
- **AAAA Record**:map ipv6 address
- **CNAME Record**: maps a domain name to another domain name
- **MX Record**: specifies the mail server responsible for handling emails for a domain
